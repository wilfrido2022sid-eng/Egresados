| PBI    | Historia de Usuario                                                                                                                                   | Criterios de Aceptación                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  |
| ------ | ----------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| PBI001 | Como Funcionario, quiero registrar nuevos egresados en el sistema, para mantener centralizada la base de datos institucional.                         | 1. El sistema debe permitir la carga individual o masiva mediante archivos planos (CSV/Excel) de nuevos egresados. <br><br>2. El sistema debe validar que el estado académico oficial del registro sea obligatoriamente "Certificado". <br><br>3. El sistema debe asegurar que el egresado cuente con un programa de formación titulada asociado. <br><br>4. El sistema debe rechazar y mostrar un error si el registro presenta estado de deserción, retiro voluntario o etapa lectiva.                                                                                                                                                                                                 |
| PBI002 | Como Egresado, quiero aceptar la Política de Tratamiento de Datos Personales, para cumplir con el Habeas Data y habilitar mi acceso al sistema.       | 1. El sistema debe presentar la Política de Tratamiento de Datos Personales del SENA con una casilla de verificación y captura de firma/log para su aceptación. <br><br>2. Si la política es aceptada, el sistema debe habilitar la navegación, edición de datos y respuesta a encuestas. <br><br>3. Si el egresado rechaza los términos, el sistema debe bloquear su acceso y actualizar su estado a "No contactable".                                                                                                                                                                                                                                                                  |
| PBI003 | Como Egresado, quiero consultar y actualizar mi información personal y laboral, para mantener mis datos vigentes en el centro de formación.           | 1. El sistema debe permitir al egresado editar sus datos de contacto (teléfono, correo, dirección, municipio de residencia). <br><br>2. El sistema debe permitir al egresado modificar su situación laboral actual. <br><br>3. El sistema debe bloquear la edición de los campos inmutables: Tipo de Documento, Número de Documento, Programa Cursado y Fecha de Certificación. <br><br>4. Al guardar los cambios, el sistema debe actualizar automáticamente el campo fecha_ultima_actualizacion con la fecha actual.                                                                                                                                                                   |
| PBI004 | Como Egresado, quiero gestionar los registros de mi trayectoria, para detallar mi historial laboral, académico y de emprendimiento.                   | 1. El sistema debe permitir crear nuevos registros hijos en los apartados de historial laboral, académico y emprendimiento. <br><br>2. El sistema debe permitir al egresado eliminar únicamente los registros específicos (hijos) que él mismo haya creado. <br><br>3. El sistema debe restringir cualquier intento por parte del egresado de eliminar su perfil completo de la base de datos.                                                                                                                                                                                                                                                                                           |
| PBI005 | Como Funcionario, quiero que el sistema identifique la información desactualizada, para gestionar alertas visuales oportunas.                         | 1. El sistema debe calcular diariamente la diferencia entre el campo fecha_ultima_actualizacion y la fecha actual del sistema. <br><br>2. Si la diferencia calculada supera los 180 días (6 meses), el sistema debe cambiar automáticamente el registro al estado "Desactualizado". <br><br>3. El sistema debe generar alertas visuales en las interfaces del área administrativa y de bienestar cuando se active este estado.                                                                                                                                                                                                                                                           |
| PBI006 | Como Funcionario, quiero diseñar formularios de seguimiento, para recolectar información estandarizada de las cohortes de egresados.                  | 1. El sistema debe permitir la creación de formularios estructurados para las encuestas de seguimiento. <br><br>2. El sistema debe permitir visualizar el histórico completo de encuestas creadas en la plataforma. <br><br>3. El sistema debe permitir asignar o publicar la encuesta para que sea visible en los perfiles de los egresados correspondientes.                                                                                                                                                                                                                                                                                                                           |
| PBI007 | Como Egresado, quiero visualizar y responder encuestas institucionales, para proveer retroalimentación sobre mi situación post-certificación.         | 1. El sistema debe listar las encuestas pendientes por responder y los avisos institucionales directamente en el perfil. <br><br>2. El sistema debe permitir completar y guardar las respuestas de las encuestas pendientes. <br><br>3. El sistema debe retirar la encuesta de la lista de pendientes una vez que las respuestas sean enviadas exitosamente.                                                                                                                                                                                                                                                                                                                             |
| PBI008 | Como Administrador, quiero gestionar registros maestros e inactivar perfiles, para mantener la consistencia y limpieza lógica de la base de datos.    | 1. El sistema debe permitir al Administrador editar los campos inmutables del egresado (documento, programa, fecha de certificación). <br><br>2. El sistema debe permitir al Administrador forzar la actualización de los estados de validación de un egresado. <br><br>3. El sistema debe permitir inactivar un registro lógicamente (soft-delete por fallecimiento, duplicidad o revocatoria) cambiando su estado a "Inactivo". <br><br>4. El sistema debe restringir por completo cualquier operación de borrado físico de la base de datos (hard delete). <br><br>5. El sistema debe retener la información anónima de los registros inactivos para métricas históricas de cohortes. |
| PBI009 | Como Visor, quiero acceder a reportes y dashboards estadísticos, para analizar indicadores de empleabilidad y emprendimiento del centro.              | 1. El sistema debe presentar tableros de control con tasas de empleabilidad, tipos de contrato y el índice de emprendimiento. <br><br>2. El sistema debe permitir filtrar la información de los reportes por programa de formación, centro y cohorte/año. <br><br>3. El sistema debe asegurar que los registros inactivados aporten a los reportes únicamente de forma anónima y como métrica histórica. <br><br>4. El sistema debe restringir completamente las acciones de creación, edición o eliminación en este módulo para el rol Visor.                                                                                                                                           |
| PBI010 | Como Visor, quiero exportar la información consolidada de los reportes, para generar los informes de gestión institucionales.                         | 1. El sistema debe tener un botón o funcionalidad para exportar los datos visibles en los tableros y reportes. <br><br>2. El sistema debe generar la exportación en formatos planos, garantizando soporte para CSV y Excel. <br><br>3. El sistema debe permitir la exportación de reportes consolidados en formato PDF.                                                                                                                                                                                                                                                                                                                                                                  |
| PBI011 | Como Visor, quiero consultar alertas específicas y registrar acompañamientos, para apoyar a los egresados en situación de vulnerabilidad o desempleo. | 1. El sistema debe mostrar indicadores de alerta sobre egresados en desempleo prolongado, vulnerabilidad o con encuestas negativas. <br><br>2. El sistema debe permitir consultar la ficha de detalle de contacto individual de los egresados listados en las alertas. <br><br>3. El sistema debe permitir crear notas de acompañamiento (bitácoras de llamadas o correos) asociadas al perfil del egresado. <br><br>4. El sistema debe restringir la edición de las notas, permitiendo que el Visor modifique únicamente aquellas que él mismo haya creado.                                                                                                                             |
